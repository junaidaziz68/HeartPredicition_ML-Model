🫀 Heart Disease Risk Prediction using Multi-Layer Perceptrons (MLP)A deep learning classification model using a Multi-Layer Perceptron (MLP) network to assess cardiovascular disease risk. Trained on a large-scale Kaggle clinical dataset containing 45,950 patient records, this project aims to assist early detection through demographic, diagnostic, and lifestyle parameters.   📌 Project OverviewCardiovascular diseases are among the leading causes of mortality globally. Machine learning models trained on extensive clinical records can identify non-linear feature interactions and detect heart risk factors early.This repository implements an MLP (Dense Neural Network) using tabular clinical data. By training across 45,950 samples, the model learns subtle interactions between lifestyle risk factors (e.g., smoking, obesity, activity level) and clinical measurements (e.g., blood pressure, cholesterol, max heart rate) to predict binary heart disease outcomes.📊 Dataset SpecificationsSource: Kaggle Clinical Heart Disease Dataset (~45,950 records)Task Type: Binary Classification (0 = Low Risk / Normal, 1 = High Risk / Disease Present)   Key Features & AttributesFeature NameDescriptionData TypeagePatient age in yearsNumericalsexGender (0 = Female, 1 = Male)Categorical / BinarycpChest pain type (0–3 spectrum)CategoricaltrestbpsResting blood pressure (mm Hg)NumericalcholSerum cholesterol (mg/dl)NumericalfbsFasting blood sugar > 120 mg/dl (1 = True, 0 = False)BinaryrestecgResting electrocardiographic results (0, 1, 2)CategoricalthalachMaximum heart rate achievedNumericalexangExercise-induced angina (1 = Yes, 0 = No)BinaryoldpeakST depression induced by exercise relative to restNumericalslopeSlope of the peak exercise ST segmentCategoricalcaMajor vessels colored by fluoroscopy (0–4)NumericalthalThalassemia statusCategoricaltarget / risk_labelHeart Disease Diagnosis Status (0 / 1)Binary Target⚙️ Data Preprocessing & PipelineData Cleaning: Handling missing, null, or out-of-range clinical values.Feature Scaling: Applied StandardScaler to continuous variables (e.g., age, trestbps, chol, thalach) for consistent gradient propagation.Encoding: Categorical features mapped via One-Hot Encoding (pd.get_dummies / OneHotEncoder).Data Partitioning: Stratified Train/Val/Test split (e.g., 70% Train, 15% Validation, 15% Test) to ensure balanced class distributions across 45,950 instances.🧠 MLP ArchitectureThe Multi-Layer Perceptron architecture is tuned for large tabular datasets to prevent overfitting while maintaining high capacity:PlaintextInput Layer (13+ Scaled Features)
